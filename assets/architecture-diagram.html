Glint — System Architecture

Self-hosted GitLab webhook receiver · Claude AI · MR reviews & release notes · Node.js / TypeScript / Docker

Glint Receiver

  • • Express / Node.js / TypeScript (strict mode)
  • • POST /webhook — MR & Release hook dispatch
  • • Fire-and-forget: 202 before AI processing (avoids GitLab timeout)
  • • Dual auth: X-Gitlab-Token OR HMAC-SHA256 signing token
  • • Stateless — no DB, no queue, restart-safe
  • • Docker: multi-stage build, non-root user, health check
  • • Fail-fast config: missing env vars abort startup

AI Integration

  • • Anthropic SDK — claude-sonnet-4-6 (default, overridable)
  • • MR: diff → Summary / Key Changes / Review Notes
  • • Release: commits → Features / Fixes / Improvements / Breaking / Chores
  • • Diff truncated at 20k chars; commits at 15k — with inline notice
  • • Only outbound call that leaves your infrastructure
  • • Model swap: set ANTHROPIC_MODEL env var

CI/CD & Ops

  • • TypeScript typecheck on every push
  • • SonarQube scan (non-blocking, MR + main + dev)
  • • Auto patch version: main push → vX.Y.Z tag via GitLab API
  • • Images: glint:dev, glint:vX.Y.Z, glint:latest
  • • GitLab Release auto-created → Glint generates AI release notes
  • • Shell runners (tagged: shell) — no docker-in-docker
  • • RELEASE_TOKEN: project access token (api + write_repository)
